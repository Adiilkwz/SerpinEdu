# Interview Template

This template is used for every user interview in `docs/02-relevance-evidence/interviews/`. 

## Interview protocol

- **Format:** online call or face-to-face, 15–25 minutes. If a call is not possible, the respondent can answer the questions in writing (e.g. in a messenger).
- **Language:** the interview can be conducted in any language; notes in the repository are written in English.
- **Consent:** before starting, the interviewer explains the purpose of the interview and asks for consent (see the script below). Interviews are not recorded unless the respondent agrees.
- **Anonymity:** no names, contacts or other personal data are stored in the repository. Respondents are referred to as "Respondent N".
- **Neutral questions:** the interviewer does not describe the planned system or gamification before section C, so that answers are not influenced.
- **Notes:** write down the respondent's answers as close to their own words as possible; mark short direct quotes with quotation marks.

### Consent script

> "We are students of Astana IT University working on a diploma project about online learning platforms. We would like to ask you about your experience with online courses. The interview takes about 20 minutes. We will not publish your name or contact details — only anonymised notes. You can skip any question or stop at any time. Do you agree to participate?"

### A. Experience with online courses (learners) — H1, H2, H4

| # | Question | Answer |
|---|---|---|
| A1 | Which online learning platforms have you used? For what purpose? | |
| A2 | How many online courses have you started in the last two years? How many did you finish? | |
| A3 | Think about the last course you did not finish. When and why did you stop? | |
| A4 | What usually makes you continue a course? What makes you stop? | |
| A5 | How do you keep track of your progress in a course? Is it important to you to see it? | |
| A6 | What do you like and dislike about the platforms you have used? | |
| A7 | Did a certificate influence your decision to start or finish a course? | |

### B. Experience as a course author or teacher (authors) — H1, H4

Ask this section only if the respondent creates or teaches courses.

| # | Question | Answer |
|---|---|---|
| B1 | On which platforms have you published or taught courses? | |
| B2 | What is difficult when creating a course: structure, tests, video, publishing? | |
| B3 | How do you check what learners have understood? Which test settings do you need (passing score, attempts)? | |
| B4 | What do you notice about learners who stop a course? At which point do they usually stop? | |
| B5 | Which information about students and income would you like to see in an author dashboard? | |

### C. Attitude to gamification — H3

Ask after sections A / B.

| # | Question | Answer |
|---|---|---|
| C1 | Have you used apps with points, levels, daily streaks, badges or leaderboards (e.g. Duolingo)? How did they affect you? | |
| C2 | Would points (XP) and levels for completed lessons and tests motivate you to continue a course? Why or why not? | |
| C3 | A daily streak counts consecutive days of study. Would it motivate you or put pressure on you? What should happen if you miss a day? | |
| C4 | Would you like to see your position on a leaderboard? Weekly, all-time or both? How would you feel if you were far from the top? | |
| C5 | Which achievements (badges) would be meaningful to you? Which would seem useless? | |
